# OLLAMA

Scripts and configuration files for my local ollama installation.

## Scripts

1. ollama-update - Updates ollama to the current release.

2. regenerate.sh - Downloads and updates all models.

3. footprint.sh - Generates a comparison of working model memory foorprint.

4. compare.sh - Compares the output of all models with a generic prompt.
